## 🧭 How to Solve "Locating Projects in Antigravity"

If you were having trouble seeing your projects in Antigravity's sidebar explorer, here is why:
- Antigravity was opened directly into the subfolder `G:\My Drive\Antigravity\Projects\index folder`.
- When an IDE is scoped to a single child folder, it cannot see sibling folders in `G:\My Drive\Antigravity\Projects\`.

### Two Easy Ways to View Everything in Antigravity:

1. **Open the Multi-Root Workspace (Recommended)**:
   - In Antigravity / VS Code, go to the top menu: `File` -> `Open Workspace from File...`
   - Select either:
     - `G:\My Drive\Antigravity\Projects\Projects.code-workspace`
     - OR `G:\My Drive\Antigravity\Projects\index folder\Antigravity_Projects.code-workspace`
   - This organizes the sidebar into grouped folders: All Projects Root, plus categorized groups!

2. **Open the Entire Projects Root**:
   - Go to `File` -> `Open Folder...`
   - Select `G:\My Drive\Antigravity\Projects`
   - Press Enter / Open.
